# Python-AI-Summarizer-Data-Collector

This is a python script that allows users to input article urls and receives an AI summary as well as reading time and word count statistics displayed in Power BI. The users are provided many options for formatting and saving .txt files for the summary display as well as .csv files for the Power BI data display.

# User Options

The script provides users with many different options when creating the AI summary and statistics files. Users are provided options and must respond accordingly. If the response does not match what the script asks for, the user is prompted the same question until a valid answer is provided.

## AI Summary Format
- Format to display a concise paragraph.
- Format as concise bullet notes.

## Running Multiple Articles
- Can choose whether they would like to continue with another article.
- Prompt posed each time after finishing 1 article.

## Multiple AI Summary .txt File
- If 1 article has already been summarized, users can choose how to save the next summary.
  - New summary can overwrite old one in same file.
  - New summary can be appended to the file with the old summary.
  - New summary can be saved to a different file.

## Multiple Article Statistsics .csv File
- If 1 article has already been used to create statistics, users can choose how to save the next .csv file.
  - New statistics can overwrite old one in same file.
  - New statistics can be appended to the file with the old summary.
  - New statistcs can be saved to a different file.
